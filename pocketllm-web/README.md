# PocketLLM Web\n\nLocal-first browser sibling of PocketLLM Lite. This workspace intentionally does not replace the repository's marketing site or Flutter web scaffold.\n\n## Run\n\n- Node.js 22 or newer\n- npm install\n- npm run dev\n\nThe Vite base path is /app/. Production hosting must preserve COOP/COEP headers so threaded WASM and supported WebGPU paths work correctly.\n\n## Validate\n\n- npm run typecheck\n- npm test\n- npm run build\n- npm run test:e2e\n\n## Data boundaries\n\nStructured state lives in IndexedDB. Large files live in OPFS. Provider keys default to session storage; optional remembered keys are encrypted locally with a user passphrase. Application-owned network calls pass through NetworkPolicyService-equivalent browser code and are audited without prompt bodies.\n
