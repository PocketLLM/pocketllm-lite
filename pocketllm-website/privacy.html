Privacy Policy

Last updated: August 29, 2026

1. Introduction

PocketLLM Lite is a local-first AI application. This policy explains what the app stores locally and when optional features may contact external services.

2. Local data

Chats, settings, prompts, personas, skills, imported documents, document indexes, memories, notes and local diagnostic logs are stored in the application sandbox unless a feature explicitly exports or sends them elsewhere.

PocketLLM Lite does not include an advertising SDK, behavioral analytics package or remote crash-reporting SDK in the current release.

3. Optional network features

Network access can occur when you choose features such as Hugging Face model discovery/downloads, Tavily web search, GitHub skill installation, update checks, an Ollama endpoint, an OpenAI-compatible provider, or an external HTTP(S) link. Those services may receive the information required for the request you initiate.

4. Strict Offline

Strict Offline is an application-level control that blocks non-loopback app-managed network requests before PocketLLM performs its own HTTP I/O. Loopback remains available for local services such as Ollama. Strict Offline is not a device firewall, and operating-system components launched after an allowed handoff are outside the app's transport boundary.

5. Device information

Where platform APIs expose it, PocketLLM can display local device information such as RAM, storage, ABI, CPU-core count, battery and thermal status. The app does not automatically upload those measurements.

6. Backups and security

New .pllm backups use password-derived authenticated encryption. You are responsible for protecting backup passwords and copies of exported data. No method of electronic storage can be guaranteed to be completely secure.

7. Third-party services

Third-party model hosts, APIs, remote providers, links and platform speech engines have their own terms and privacy behavior. Review the applicable service before enabling it.

8. Your controls

You can inspect, edit, export or delete available local data through PocketLLM controls; disable optional network features; enable Strict Offline; or clear application data through operating-system controls.

9. Website

The project website links to GitHub and may load web fonts from third-party infrastructure depending on deployment. The static marketing pages do not require a PocketLLM user account.

10. Changes

This policy may change as the project evolves. Material changes should be reflected in the repository and the updated date above.

11. Source and questions

For implementation details, inspect the open-source repository, security policy, and known limitations.
