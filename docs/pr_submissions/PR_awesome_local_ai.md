# Pull Request: Add PocketLLM Lite to Inference UI section

## Description
This PR adds [PocketLLM Lite](https://github.com/PocketLLM/pocketllm-lite) to the **Inference UI / Mobile Clients** section of `awesome-local-ai`.

PocketLLM Lite is a source-available Flutter/Android LLM client built for compatible local GGUF execution, configured Ollama streaming, and local document RAG. The repository currently has no root license grant and must not be described as open source until the owner adds one.
