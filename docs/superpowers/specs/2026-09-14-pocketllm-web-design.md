# PocketLLM Web design\n\nPocketLLM Web is an account-free browser sibling of the Flutter app. The marketing site and Flutter web scaffold stay intact. The browser product lives in pocketllm-web/ and deploys at /app/.\n\n## Architecture\n\nReact, TypeScript and Vite provide the shell. Dexie/IndexedDB stores structured state and OPFS stores model, document, audio and attachment bytes. AI execution sits behind runtime adapters for wllama GGUF, Chrome built-in AI, Ollama and OpenAI-compatible endpoints.\n\nAll application-owned network I/O uses one policy gateway so Strict Offline can block LAN/Internet traffic before I/O and record safe audit metadata. Tools use strict schemas and risk-based confirmation. RAG combines BM25, local embeddings, hybrid scoring and MMR. Web and mobile share the encrypted .pllm cryptographic envelope.\n\n## UX\n\nDesktop uses a navigation rail, main workspace and optional context inspector. Compact screens use a drawer and one-column surfaces. The visual system is a restrained editorial workspace: atmospheric neutral outer canvas, paper-like surfaces, serif display typography, quiet violet accent, subtle borders and dense expert screens where useful.\n\n## Browser boundaries\n\nA standard browser cannot expose an inbound OpenAI-compatible TCP server, provide portable hardware-backed secret storage, or guarantee exact reminders after every browser is fully closed. The UI states those limits rather than simulating success.\n\n## Quality gates\n\nTypeScript, unit tests, production build and Playwright desktop/mobile smoke tests run in CI. Cross-platform schemas and parity/features.yaml make feature drift visible. Accessibility includes keyboard operation, visible focus, reduced motion and text scaling.\n
